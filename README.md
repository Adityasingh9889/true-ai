# True AI 🤖

A Python-based AI assistant project focused on conversational interaction and local data handling.

## Project goals
- Experiment with AI assistant workflows
- Explore local memory and conversation state
- Practice Python application structure

## Tech
- Python
- Local application data

## Security note
Runtime databases and local memory files should not be committed when they may contain personal or user-generated data. Keep those files local and use environment/configuration files for deployment settings.
